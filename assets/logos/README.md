# Logo sources

Original project logos, downloaded from their official websites:

| Project | Original file | Source |
| --- | --- | --- |
| KVM | `kvm.png` | [KVM website banner](https://www.linux-kvm.org/kvmless/kvmbanner-logo3.png) |
| QEMU | `qemu.svg` | [Original logo in the QEMU source tree](https://github.com/qemu/qemu/blob/master/ui/icons/qemu.svg) |
| libvirt | `libvirt.svg` | [Official square logo](https://www.libvirt.org/logos/logo-square.svg) · [Logo documentation](https://www.libvirt.org/logos/index.html) |
| oVirt | `ovirt.svg` | [Official profile logo](https://www.ovirt.org/images/profile-logo.svg) · [Logo documentation](https://www.ovirt.org/logo.html) |

The original files are unchanged. `../virtualization.svg` embeds these assets in
a self-contained row, scales them proportionally, and adds backgrounds and labels.
